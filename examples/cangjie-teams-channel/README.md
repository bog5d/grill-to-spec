# Example 001 — 仓颉 Teams Channel

这是 Grill to Spec 的第一场真实 dogfood。

## 一句话目标

构建一个 AI 可直接接手、团队可持续积累知识和能力的可迁移工作项目包；V1 从“录音导入 → 清洗 → 建档 → 可查询”切入。

## 已钉死的关键边界

- 产品名：仓颉 Teams Channel。
- 公共区默认团队成员均可访问财务、法务、业务、录音等共享资料。
- 领导私人洞察/评价物理隔离，不靠权限隐藏。
- 原始资料可自动汇集；知识、规则、Skill、功能必须 Gate 后才能成为正式公共版本。
- Gate = PASS / FAIL / UNCERTAIN；不确定不晋级。
- V1 低风险词库/结构化索引可自动晋级；代码/Skill/核心规则只自动预审，最终人工确认。
- 自动审核长期目标 90%，人工 10%。
- V1 不做 Web UI、复杂权限、多租户、Dashboard。
- 大文件 Data Plane 不进 Git；系统/规则/Skill 属 System Plane。

## V1 Gate

新人拿到项目包后，AI 能接手并说明能力；用户投入一批录音后可完成识别/清洗/基础索引/词库候选，并可回答会议数量、人员参与、材料处理状态等基础查询。
