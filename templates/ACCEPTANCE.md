# ACCEPTANCE

## Outcome Gate（先于工程 Gate）

- [ ] 用户可观察的最终结果及反例写清楚，不使用代理指标替身
- [ ] 当前业务基线有证据，工程完成率与最终目标效果分开
- [ ] 核心任务在正式或等效测试环境端到端实测，产物可由独立 Reviewer 检查
- [ ] 无人值守/长期任务：开发会话退出后仍完成真实执行→Gate→接棒；仅心跳不足以 PASS
- [ ] 关键业务硬门槛 FAIL 时，禁止宣布目标完成

## 工程 Gate

- [ ] 核心用户能完成第一使用场景
- [ ] 关键失败场景有确定性处理
- [ ] State 可中断恢复
- [ ] Evidence 可独立验证
- [ ] 无违反安全/保密边界
- [ ] 通过 SCP v3.8 适用等级的 Preflight
- [ ] 测试/validate/evals（如适用）有真实结果
